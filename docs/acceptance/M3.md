# M3 手机验收清单（任务队列 + 本机执行员 + 接管卡 + 定时签到）

> 执行员线起草；后台线、控制台线如有改动直接改本文件。一共 5 条，约 10 分钟。需要 #117（Core MCP 任务工具）和 #111/#120 合并并部署后才能做第 5 条。

| # | 做什么 | 应该看到什么 |
|---|---|---|
| 1 | 电脑上运行 `executor\scripts\install-windows.ps1`，按提示粘贴控制台「本机执行员」页生成的令牌；手机打开控制台「本机执行员」页 | 页面「设备」里出现你的电脑，状态「在线」；电脑重启后 1 分钟内又变回「在线」 |
| 2 | 在控制台「本机执行员」页对白名单里的一个网站点「现在就签到」（或在聊天里对负责人说「帮我在 xx 站签到」） | 任务列表出现一条「排队中」，几十秒内变「进行中」，最后变「成功」，摘要里写明已签到或今天已签到；电脑上能看到浏览器自己操作 |
| 3 | 派一个会出验证码的登录任务 | 收件箱出现「接管卡」（验证码/两步验证）；在电脑浏览器里自己完成后，点卡上的「我已处理」，任务接着跑完变「成功」 |
| 4 | 再派一个任务，接管卡出现后点「放弃」 | 任务变「已取消」，电脑上浏览器页面关闭，不再重试 |
| 5 | 在 LobeHub 建每天定时任务（写法见 docs/executor-schedule.md），点「立即运行一次」 | 控制台任务列表多出一条同站点的任务；当天重复触发不会多出第二条 |

不用做：日志、令牌、密码都不会出现在任何页面上；如果哪一步看到了明文密码或验证码，立刻告诉 Hark（这是红线问题）。
