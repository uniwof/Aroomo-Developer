# M1 手机验收清单（控制台 + 能力清单 + 群组路由）

> 控制台线起草；一共 5 条，约 10 分钟。第 1 条需要 #109 合并并部署（手机才能打开控制台）；第 5 条需要 LobeHub API 密钥（V2）并跑过 lobe-sync。

| # | 做什么 | 应该看到什么 |
|---|---|---|
| 1 | 手机打开 app.pcmanai.com，登录后进入 /console | 打开「Aroomo 控制台」，有 Aroomo Logo 和额度圆环，左侧/顶部有 7 个入口；字不小、按钮好点 |
| 2 | 进「能力地图与成员」，看顶部那一行 | 显示「文本 N · 生图 N · 视频 N」；每一项都有「永久免费」或「试用」徽标；查不到额度的写「未知」，不会显示假数字 |
| 3 | 点一个标「试用」的项，填一个到期日并保存 | 徽标旁出现「还剩 N 天」和到期日；刷新后还在 |
| 4 | 进「Key 与接入」，看已有的 Key | 只看到名称和后 4 位，任何地方都看不到完整 Key |
| 5 | 在 LobeHub 的群组里发一句不 @ 任何人的话，再发一句 @某个成员 | 不 @ 时由负责人回答；@ 成员时由该成员回答 |

不用做：不会出现明文 Key、密码或验证码；如果看到了，立刻告诉 Hark（红线问题）。
