# M1 手机验收（10 分钟，5 条）

> 每条：做一件事，看对不对。对就说「好」，不对就说哪条。
> 现在先测第 1–4 条。第 5 条要等 Hark 换好额度够的免费模型，到时会告诉你（D246）。

1. 手机打开 app.pcmanai.com/console，登录。
   应该看到：Aroomo 标志、一个圆环，和几个大按钮，字够大、好点。

2. 进「能力地图与成员」，看最上面一行。
   应该看到：「文本 几个 · 生图 几个 · 视频 几个」，每项写着「永久免费」或「试用」；不知道的写「未知」，不会是假数字。

3. 点一个写着「试用」的，填一个到期日，保存，再刷新页面。
   应该看到：写着「还剩 几天」，刷新后还在。

4. 进「Key 与接入」。
   应该看到：只有名字和最后 4 个字符，哪里都看不到完整的 Key。

5. 打开群组「Aroomo M1 验收群」。先发一句不带 @ 的话，再发一句开头写 @groq-oss120b 的话。
   应该看到：不带 @ 时负责人回答；带 @ 时 groq-oss120b 回答。

看到完整的 Key、密码或验证码，马上告诉 Hark。
