# M4 手机验收清单（收件箱 + 确认卡 + 试用提醒 + 连续使用）

> 控制台线起草（工单 #231，D253）。一共 4 条，约 10 分钟，全部用手机做。按 PROJECT.md 里 M4 的验收①–④写。短句，没有表格，可以用读屏软件读。

## 一、连续用

目标：真实用一天以上，再用假时钟模拟第二天，没有人被锁在门外，也没有多花钱或丢数据。

1. 今天正常用：聊天、收件箱、资源库各用几次。
2. 过了北京时间零点之后，再用一次。
3. 应该看到：还是登录状态，能正常聊天；额度圆环从零开始重新数；昨天的内容都还在。
4. 假时钟测试：在 CI 里看 core 的测试任务是绿的。测试覆盖五件事：每日限额零点清零、确认卡 5 分钟过期、过期记录清理、令牌过期、夜间备份。每一件都有两个账号互不影响的断言。
5. 假时钟测试的结果链接：工单 #230，测试文件 core/test/clock-*.test.ts（PR #239 已合入，CI 的 Core 任务是绿的）。
6. 通过标准：第 3 条和第 4 条都满足。

## 二、收件箱和确认卡

目标：需要你拍板的事都进收件箱，而且在手机上能处理。

1. 打开控制台，进「收件箱」。
2. 应该看到：需要你决定的事、接管卡、简报，分别在各自分组里；每张卡标题一句话说清是什么事。
3. 点一张带重要操作的卡，选主要操作。
4. 应该看到：一张确认卡，先写标题，再写会发生的全部后果。
5. 点「继续」。第二个按钮有 3 秒倒计时，倒计时结束才能点。
6. 点第二个按钮。应该看到：操作完成，卡片从待处理里消失。
7. 再来一次，但这次点完「继续」后等超过 5 分钟再点第二个按钮。
8. 应该看到：提示已过期，操作没有执行，需要重新开始。
9. 通过标准：手机上不用放大、不用横屏就能做完整个过程。

## 三、试用到期提醒

目标：试用快到期之前，系统会提醒你。

1. 打开「工具」页或能力地图，找一个有试用徽标的服务。
2. 给它填一个到期日，选三天以内的日期。
3. 应该看到：徽标旁显示剩余天数和到期日。
4. 等下一次检查（每 6 小时一次；Hark 验收时可以手动触发）。
5. 应该看到：收件箱里出现一张试用到期提醒卡，写明是哪个服务、还剩几天。
6. 把到期日清空。应该看到：徽标上的天数消失，不再提醒。
7. 通过标准：第 3 条和第 5 条都看到。

## 四、试用中报的问题

目标：这几天你报过的问题都已经处理。

1. 在进度 Issue 里找「试用问题」清单。
2. 应该看到：你报过的每一条，都标成「已修复」或「已决定不修」，并写明原因。
3. 对「已修复」的每一条，用手机再试一遍。
4. 应该看到：不再出现。
5. 通过标准：没有「未处理」的条目；11 月 4 日 12 点以后只修 bug，不再加新功能。

## 不用做

- 日志、令牌、密码都不会出现在任何页面上。如果哪一步看到了明文密码或验证码，立刻告诉 Hark（红线问题）。
- 两个账号互相看不到对方东西的检查，见 two-accounts.md，由 Hark 先在 staging 做完。
