# Aroomo 立项卡 + 一页需求（PROJECT.md）

> 按《通用项目开工规范 v1》第 6 节（D244）。从 PRODUCT.md 2.1 与 D203 里程碑提炼，**不新增需求**。功能有争议以本页为准；细节按编号去 DECISIONS.md 查。

## 一句话目标
把散落各处的免费 AI 收拢成「AI 公司」的员工：所有者提需求，负责人派活，成员分工完成，过程可查，后台员工代办签到等杂事。

## 给谁用
快跑阶段（M1–M4）只给所有者本人用（加一个测试小号做两个账号验收）；手机为主、电脑跑本机执行员。邀请亲友前先过加固（D213 商用就绪清单 100%）；收费排在加固之后（D222）。

## 必须有的功能（7 条，每条一个验收动作）
| # | 功能 | 做什么 → 应该看到什么 |
|---|---|---|
| 1 | 控制台 + 能力清单 | 手机打开 /console → 看到「文本 N · 生图 N · 视频 N」，每项有永久免费/试用徽标，查不到写「未知」 |
| 2 | 群组路由走 Core | 群组里 @ 某成员 → 只有它答；不 @ → 负责人答（各成员用自己的模型） |
| 3 | Key 安全 | 进「Key 与接入」→ 只见名称和后 4 位，任何页面都看不到完整 Key |
| 4 | 工具网关 | 让负责人调用一个外部工具 → 调用成功并回报结果 |
| 5 | 资源库 + 规矩注入 | 粘贴一个网址保存 → 问负责人「资源库里有什么关于 X 的」→ 能答出来 |
| 6 | 本机执行员 + 接管卡 | 交代「去 X 网站签到」→ 电脑上完成并回报；碰到验证码手机收到接管卡 |
| 7 | 收件箱 / 确认卡 / 试用到期提醒 | 连续用 2 天 → 需要拍板的事都进收件箱，试用快到期有提醒，没有阻塞问题 |

## 明确不做（快跑阶段）
- Windows 离线版 / 独立版、桌面安装包（冻结，D238；只保留本机执行员安装与更新）
- Valkey 缓存、GlitchTip（推到加固，D237）
- 公开目录及其字段预留、R2 签名资源目录（D237；R2 每日加密备份照常）
- 订阅分级、支付（收费前，D219–D222）
- 朗读 TTS 与 D12 已取消的设计；B/C 类模型审查（#185）
- 新的流程工具（CI、机器人、派工脚本）：冻结，只修不加（规范铁律 7）
- 其余延后项见 POOL.md

## 约束
- 红线见 CONTEXT.md（D199）：密钥不进仓库/日志/上下文；花钱/不可逆/凭据走确认；新依赖可商用、零授权费；不改 LobeHub。
- 底座：官方 LobeHub 原样 + Aroomo Core；部署可移植（D9）。
- 所有者不懂技术：只负责要什么、验收、花钱、凭据；dev→main 只由所有者合。
